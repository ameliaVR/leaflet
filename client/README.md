# Leaflet — React + TypeScript frontend

## Запуск у Windows PowerShell

```powershell
cd C:\Users\User\leaflet\client
npm.cmd install
npm.cmd run dev
```

Якщо завантажено ZIP, замініть вміст існуючої папки `client` файлами з `leaflet-react/client`.

## Реалізовано
- Головна сторінка, каталог із пошуком і фільтрами, додавання книг, профіль, власна бібліотека.
- Два типи оголошень: `exchange` та `giveaway`.
- Кольори, шрифт, форми й картки адаптовані з коричневої HTML-версії.
- TypeScript типи для книг і профілів, React state, React Router.

## Важливо
Це **frontend-демоверсія**, не production backend. `src/services/api.ts` використовує `localStorage`, тому записи не видно на інших пристроях. Реєстрація, справжня авторизація, контакти інших власників, запити на обмін, завантаження фото на сервер та PostgreSQL ще не підключені. Демонстраційні користувачі не є реальними акаунтами. Контакти інших людей навмисно не вигадуються.

## Наступний етап
Node.js + Express + PostgreSQL, міграції БД, реєстрація, авторизація, оголошення та безпечні публічні контакти за згодою власника.
