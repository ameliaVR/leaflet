# Leaflet — React + TypeScript + Express + PostgreSQL

## Передумови
Node.js (LTS), PostgreSQL із створеною базою `leaflet`.

## 1. База даних
У PostgreSQL створіть базу даних `leaflet` (наприклад, через pgAdmin).

## 2. Сервер
Відкрийте **перший термінал** у папці `server`:

```powershell
Copy-Item .env.example .env
```

Відредагуйте `server/.env`: вкажіть справжній пароль PostgreSQL у `DATABASE_URL`. Не завантажуйте `.env` до Git.

```powershell
npm.cmd install
npm.cmd run db:init
npm.cmd run dev
```

Сервер працює на `http://127.0.0.1:3001`.

## 3. Frontend
Відкрийте **другий термінал** у папці `client`:

```powershell
npm.cmd install
npm.cmd run dev
```

Відкрийте `http://127.0.0.1:5173/`. Зареєструйте тестовий акаунт.

## Що працює
- Реальна реєстрація, вхід, вихід і відновлення сесії після оновлення сторінки.
- Паролі хешуються Argon2id, cookie HttpOnly, сесії зберігаються у PostgreSQL.
- Профіль (ім'я, місто, опис, контакт і згода на показ) зберігається у PostgreSQL.
- Сторінки додавання книги, профілю і бібліотеки закриті для гостей.

## Що поки НЕ працює як багатокористувацький сервіс
Каталог, книги та обране **все ще демоверсія в localStorage браузера**. Книги не зберігаються у PostgreSQL, не прив'язані на сервері до акаунта та не доступні іншим користувачам. Наступний етап — серверні таблиці оголошень, їх API і міграція React-сторінок на `fetch`.

## Безпека
Це навчальний стартовий проєкт, не готовий до публічного продакшн-запуску. Перед публікацією потрібні HTTPS, CSRF-захист для cookie-сесій, підтвердження email, відновлення пароля, міграції БД, перевірка прав доступу до книг, налаштування CORS та rate limiting.
